## User Journey Specification

**Primary Persona:** Venu — Solo dev, runs JARVIS on WSL, checks phone mornings, uses TUI at desk, reviews Grafana weekly.

| Phase | Trigger | User Context | Emotional State | UI Touchpoint | Key Action | Success Metric |
|-------|---------|--------------|-----------------|---------------|------------|----------------|
| **1. Morning Alert** | ntfy.sh push | Phone in hand, coffee | 😰 "Did it work?" | Mobile Alert List → Detail | Tap critical → view message + actions | < 3 sec to actionable info |
| **2. Triage** | Open terminal | At desk, multiple tabs | 😤 "What's broken?" | `jarvis status` (TUI) | Scan services (all green?) → check logs | < 10 sec to "all healthy" |
| **3. Investigate** | Warning alert seen | Focused, coffee cooling | 🤔 "Why Naukri failing?" | Grafana Dashboard → Portal Errors | Drill error bar → selector history | < 30 sec to root cause |
| **4. Remediate** | Found broken selector | Ready to fix | 🛠️ "Let me fix this" | TUI → filter failed → Retry | Click Retry → toast "3 jobs retried" | < 1 min to remediation |
| **5. Weekly Review** | Monday morning | Planning week | ✅ "How'd we do?" | Grafana → Cron Success + Apply Rate | Screenshot → share to Notion | Ritual complete |

**Journey Principles:**
- **Mobile → Desktop continuity:** Deep link `jarvis://alert/ALT-0042` opens same alert in TUI/Grafana
- **Progressive disclosure:** Alert list → Detail → Runbook → Action
- **No dead ends:** Every screen has primary action; empty states have CTAs
- **Time-boxed:** Each phase targets < 30 sec except deep investigation

## Edge Case Specification (PARANOIA PASS)

**Every UI artifact MUST handle:**

| Edge Case | Grafana Dashboard | CLI TUI | Mobile Alerts |

## Accessibility & Trust Specification

### Accessibility (WCAG 2.1 AA Minimum)

| Requirement | Grafana Dashboard | CLI TUI | Mobile Alerts |
|-------------|-------------------|---------|---------------|
| **Contrast** | All text 4.5:1; UI elements 3:1 | Textual defaults (pass); custom colors verified | iOS system colors (pass); custom #ff3b30 on white = 4.5:1 |
| **Keyboard** | Full dashboard navigable (Tab, arrows, Enter) | Full keyboard control (j/k, Enter, r, f, q, ?) | Touch only; deep links for desktop parity |
| **Focus** | Visible ring (2px, #0066ff); focus order logical | Cyan ring (2px); focus trap in modals | N/A (touch); visible selection state on tap |
| **Labels** | All filters, buttons, links have accessible names | Textual built-in; custom widgets need aria-label | VoiceOver labels on all interactive elements |
| **Live Regions** | Auto-refresh announces "Dashboard updated" | Log area announces new errors (polite) | Alert arrival announces (assertive for critical) |
| **Language** | `lang="en"` on html; filter labels descriptive | Terminal inherits locale | `lang="en"`; dynamic type respected |

### Trust Signals (Pixel-Level Intentionality)

| Trust Signal | Grafana Dashboard | CLI TUI | Mobile Alerts |
|--------------|-------------------|---------|---------------|
| **Data Freshness** | "Last updated: 10:32:18" in header; each panel shows data timestamp | Header: "Last updated: 10:32:18"; stale badge after 2 min | Each card: "10:32 AM"; detail: full ISO timestamp |
| **Source Attribution** | Panel subtitle: "Source: Prometheus (job_automation)" | Log lines: "[naukri] Applied..." source prefix | "Job Automation" / "Model Router" / "Ollama" badges |
| **Audit Trail** | Drill-down → query inspector → raw PromQL + result | Logs immutable; `jarvis logs <job_id>` shows full trace | Alert ID (ALT-0042) links to runbook + Grafana panel |
| **No Silent Failures** | Failed queries show error panel + retry | Failed service = red dot + tooltip; logs show error | Failed push → in-app banner + retry button |
| **Reversible Actions** | Filters reset button; time range undo | `q` quits without saving; `r` refreshes | Acknowledge → undo in 5s toast; Dismiss → recover in Settings |
| **Privacy** | No PII in panel data (job IDs hashed) | No secrets in logs (sanitized) | ntfy.sh payload: no secrets, only alert metadata; deep link opaque ID |
